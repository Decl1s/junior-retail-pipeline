# Приватность и состав публичного релиза

Генератор создаёт заказы из констант и начального значения случайных чисел.
Он не читает профиль, браузер, документы, почту, секреты окружения или другие проекты.
Конвейер читает только выбранные локальные CSV. Сетевых запросов, аналитики,
телеметрии и личных контактов в приложении нет.

Если обработать настоящие данные, база и отчёт останутся чувствительными,
даже без прямых идентификаторов людей. Не публикуйте их автоматически.
Карантин хранит только коды ошибок, хэши источников и позиции строк.
Командный интерфейс не выводит исходные строки и приватные пути.

`PUBLIC_FILES.txt` задаёт точный список публикуемых исходников.
`scripts/check_public.py` отклоняет лишние отслеживаемые файлы, символические ссылки,
типичные ключи доступа, email и пути к домашним папкам в содержимом исходников.
`scripts/package_release.py` собирает ZIP только из проверенного списка.
В архив не входят история Git, входные данные, база, локальные отчёты, кэши,
виртуальное окружение и материалы других проектов.

Небольшая проверка не доказывает безопасность любого будущего содержимого.
Просматривайте каждое публичное изменение. Для авторства рекомендуется служебный
адрес GitHub no-reply. Адреса из метаданных коммитов видны в публичной истории;
проверка сообщает об адресах вне домена no-reply, не печатая сами адреса.
Это примечание не блокирует сборку. Контакты в исходниках по-прежнему запрещены.
Установка зависимостей и GitHub Actions используют сеть независимо от локальной обработки.
