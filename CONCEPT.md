# Концепция проекта

Небольшой проект для портфолио начинающего дата-инженера на синтетических событиях продаж.
Запуск через Python в Linux и Windows; отчёт открывается в браузере.
Для этого проекта запрошен публичный GitHub. Личные контакты и настоящие данные исключены.

По просьбе самостоятельно выбрать проект были предложены десять коротких уточнений.
До отдельных ответов используются выбранные значения. Следующим указанием весь
пользовательский интерфейс и документация переведены на русский.

| Решение | Выбранный вариант |
| --- | --- |
| Предметная область | Заказы магазина |
| Размер демо | 10 000 заказов |
| Загрузка | Пакетные CSV |
| Обновления и дубли | Версии событий, повторный запуск без дублей |
| Ошибки | Шесть ошибочных демострок и карантин с причинами |
| Результат | SQL-витрины, CSV, Parquet, JSON и локальный HTML |
| Язык | Русские инструкции, отчёт, справка и сообщения; стандартные технические имена |
| Установка | Виртуальное окружение Python |
| Портфолио | Разбор учебного проекта для собеседования |
| Репозиторий | junior-retail-pipeline |

Версия 0.1.0 готова, когда отдельное окружение создаёт демо, загружает поставки,
сохраняет суммы при повторе, откатывает конфликтующий пакет, формирует отчёт
и проходит проверки. Состав релиза должен совпадать с явным списком исходников,
контакты и личные данные не должны попадать в содержимое исходников.
Метаданные авторства публичной истории Git доступны посетителям репозитория.

Будущие возможности перечислены в README. Промышленная эксплуатация, большие объёмы,
настоящие платежи и обработка клиентских данных в готовность этой версии не входят.
